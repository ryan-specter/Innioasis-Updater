With Innioasis Updater you just select the firmware you would like to install, follow the instructions shown on screen, and away you go. The app and this site also tell you about updates and issues that arise with that firmware. MTKClient is bundled with Updater’s Toolkit for the cases where the guided install cannot run, and the low-level recovery notes below are for those cases only.

Understanding BootROM (BROM) Mode

When powered completely down, the MediaTek MT6572 / MT6580 processor listens on the USB bus for a handshake packet before loading the primary bootloader. If a corrupted flash occurs, BROM mode allows a full recovery rewrite.
