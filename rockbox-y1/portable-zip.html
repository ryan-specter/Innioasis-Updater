Rockbox-Y1 · Innioasis Y1

Rockbox-Y1 portable ZIP

The portable ZIP is the no-wizard path: a release archive that contains the ROM images for this player, arranged so Updater CE can flash them from a local folder — or so you can hand the folder to the manual flashing tool of your choice.

Get it in Updater CEFull written tutorial

Pick the archive for your computer

  • rom-windows.zip, rom-macos.zip, rom-linux.zip — the same ROM, packaged for each platform's default extraction and path handling.
  • rom.zip — the universal package when you want one file for every machine.
Rockbox-Y1 downloadsGet it in Updater CEMirror release stable-v0.5

Install from the extracted folder

  1. Download the ZIP and extract it to a path with no spaces or unusual characters.
  2. Open Updater CE, set Device Model to Y1.
  3. Choose the local-package / browse option and point it at the extracted folder.
  4. Confirm the images it found, then run Install / Restore.
  5. Power the Y1 off and connect it only at the prompt.

What is inside

A scatter file plus the partition images the flash writes. The scatter is what tells the flashing tool where each image belongs, and it is why the extracted folder must stay intact — moving a single image out breaks the mapping.

Questions people ask

Do I need Python or MTKClient installed?

No. Updater CE bundles what it needs; the ZIP is only the ROM.

Can I keep the ZIP on the SD card?

You can store it there, but flashing reads it from the computer. Extract it on the machine doing the flash.

The folder has several images — do I flash all of them?

Yes, the flash writes the set the scatter names. Do not cherry-pick.
