Rockbox-Y1 install problems and how to fix them

A Rockbox-Y1 install fails in a small number of recognisable ways. Work through them in this order — most people find their answer in the first three.

Get it in Updater CEFull written tutorial

In the order worth trying

  1. Wrong model selected: confirm Y1 in Device Model before choosing Rockbox.
  2. Cable: swap for a known data cable; charge-only cables never enumerate.
  3. Timing: the preloader window is only a few seconds. Start the flash, then connect the powered-off player.
  4. Drivers and permissions: install the MediaTek preloader driver on Windows, fix 0e8d:* permissions on Linux (drivers page).
  5. Interrupted transfer: reconnect and repeat; if the player no longer appears at all, follow the recovery guide.

Where it usually stops

Before the USB prompt the problem is almost always the computer or the package. After the player is detected, the problem is the connection or the ROM. That split is what the troubleshooting page is organised around.

Questions people ask

Updater says it cannot find the player. What now?

Connect it powered off, in the same moment the app starts listening, and check the cable and driver first.

The flash reached 99% and stopped. Is the player dead?

Usually not. Repeat the flash; a player that will not enumerate needs the recovery route.

Can a bad MicroSD card break the install?

Not the flash itself, but it will break the first boot's database build. Try another card.
