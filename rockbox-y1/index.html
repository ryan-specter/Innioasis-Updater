Rockbox-Y1 · Innioasis Y1

Rockbox-Y1

Rockbox-Y1 is the Innioasis Y1 build of Rockbox: community firmware that replaces the stock player with a tag-based library, gapless playback, an equalizer and a deep theme library. This page is the index for everything on this site about Rockbox-Y1 — install steps, ROM downloads from the portable mirror, themes, restoring the original software, and the fixes worth trying when a flash stops.

Rockbox, Rockbox-Y1 and “Rockbox for Y1” are the same software

The project publishes one port per player. The catalogue lists it as Rockbox with device Y1; search engines, videos and forum posts call the same build Rockbox-Y1, Rockbox for Y1, or rockbox-y1 in a URL. Nothing differs between the names — only the spelling. What does matter is the model: a Y1 build is not a Y2 build.

The release notes for this software are titled Rockbox-Y1 release notes so the version history and the search result agree on the name.

Downloads come from the portable mirror

Updater CE downloads and flashes the ROM for you. If you want the files in hand — to flash from another computer, to keep an archive, or to install from a local package — take them from the y1-community/rockbox-mirror mirror. Its releases carry the same ROM as per-platform portable ZIPs, including Type B variants where the Y1 needs one.

Before you flash

  • Set Device Model to Y1 before you pick Rockbox.
  • Prefer a stable release unless you are deliberately testing a nightly build.
  • Use a data cable and a charged battery; connect the powered-off player only when Updater asks.
  • The flash replaces the player software. The matching Original Software package is the way back.

Y1 community builds are labelled by resolution: 240p builds have the broadest older-theme compatibility, 360p builds are made for the newer Y1 theme path.

Questions people ask

Is Rockbox-Y1 safe to install?

It runs on the same flashing path as the stock firmware, and the community has installed it on many players. It is still custom firmware on a MediaTek device: an interrupted flash can leave the player needing a recovery run, so use a good cable, a charged battery and do not disturb the connection.

Can I put the Rockbox-Y1 build on a Y2?

No. The two ports are separate packages. Select Y2 in Updater CE and use the Rockbox-Y2 pages instead.

How do I go back to the original software?

Choose Y1 again, select Original Software, pick a stable release and run Install / Restore. The restore page walks through it.
