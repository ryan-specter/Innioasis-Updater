Rockbox-Y1 FAQ

The questions that come up first about Rockbox-Y1, answered plainly — with links to the page that goes deeper.

Short answers

Rockbox, Rockbox-Y1 and “Rockbox for Y1” are the same port for the Innioasis Y1. You install it with Innioasis Updater CE by selecting the model, choosing Rockbox, picking a release and connecting the powered-off player when the app asks. You undo it by flashing Original Software for the same model.

Questions people ask

Is Rockbox the same as Rockbox-Y1?

Yes. The catalogue lists the software as Rockbox with device Y1; this site titles its release notes Rockbox-Y1 so the name matches what people search for.

How do I install Rockbox on the Y1?

Use the install page: model first, then Rockbox, then a stable release, then the USB prompt.

Which file do I download?

The download page lists the portable ZIPs per platform and the universal ROM; the app downloads the same package for you.

Can I use the Rockbox-Y1 build on the Y2?

No. Use Rockbox-Y2 for that model.

Will I lose my music?

No. Music sits on the MicroSD card; flashing the ROM does not erase it.

How do I go back?

Flash Original Software for Y1 — restore page.

Is it safe?

It uses the same MediaTek flashing path as stock firmware. Use a good cable, a charged player, and do not interrupt the flash.
