Rockbox-Y1 · Innioasis Y1

Remove Rockbox-Y1 or reset it to defaults

“Uninstall Rockbox-Y1” usually means one of two different things, and they have different answers: going back to the original software, or resetting the settings the build keeps on the card.

Get it in Updater CEFull written tutorial

Going back to the original software

This is a flash, not a deletion. Select Y1, choose Original Software, pick a stable release and run Install / Restore. The restore page has the full sequence.

Resetting only the settings

Delete or rename the .rockbox folder on the MicroSD card and boot again. That clears settings, themes and caches, leaves the firmware installed, and reverts the player to defaults — see the MicroSD page.

Questions people ask

Does deleting .rockbox remove the firmware?

No — it removes settings and themes; the build rebuilt the folder on the next boot.

Can I reinstall later?

Yes, the release stays in the catalogue for this model.

Is either operation reversible?

Yes, in both directions: flashing Original Software and flashing Rockbox again.
