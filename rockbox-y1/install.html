Install Rockbox-Y1 on the Innioasis Y1 (Updater guide)

Installing Rockbox-Y1 is a guided flow in Innioasis Updater CE. The order matters more than the clicking: the model comes first, then the software, then the release, and the player is connected last — powered off — only when the app asks for it.

Get it in Updater CEFull written tutorial

The install, step by step

  1. Open Innioasis Updater CE and set Device Model to Y1.
  2. Choose Rockbox in Software — the release data may label it Rockbox-Y1.
  3. Choose a stable release (or the nightly you mean to test).
  4. Click Install / Restore and let the package download and extract.
  5. Power the Y1 fully off, then connect the USB data cable only when Updater asks.
  6. Disconnect only after the success message, then start the player.

Why the model comes first

Updater CE filters releases by the model you select. Picking Rockbox before the model is how people end up staring at a Y2 package on a Y1 player. The catalogue row for this software is rockbox-y1 with device Y1, so as long as the model is right the release list is right.

If you would rather not use the app, the same ROM is available as a portable ZIP — see installing from a portable package.

What Updater does with the package

It downloads the ROM, unpacks the images, and writes them with MediaTek's download protocol through either SP Flash Tool or MTKClient depending on your platform. The player does not need to boot into anything special: it is flashed in preloader mode, which is why it must be off and connected at the right moment.

Questions people ask

How long does a Rockbox-Y1 install take?

Usually a few minutes once the ROM is downloaded; the download itself is the slow part on a typical connection. Leave the player alone until Updater reports success.

Do I need to unlock or root the Y1 first?

No. The flash uses the MediaTek preloader, so there is nothing to unlock beforehand.

Which release should I pick?

A stable release is the default answer. Nightlies are for testing a specific fix and are labelled as previews in the app and on the release-notes pages.
