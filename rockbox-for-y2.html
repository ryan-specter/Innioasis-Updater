Rockbox for Y2 is Rockbox-Y2

The Y2 has its own Rockbox. It is not the Y1 build with a different label: different project, different ROM package, different mirror, and a beta line that moves at its own pace.

Same name, different build

“Rockbox” is the project; “Rockbox-Y2”, “Rockbox for Y2” and rockbox-y2 are how people name the port for this player. The catalogue lists it as Rockbox with device Y2, published from the spycemagic/y2-rockbox repository, and its ROM package is named rom_y2.zip — a filename worth remembering, because it is the quickest way to tell a Y2 download from a Y1 one.

The Y1 package will not appear when Y2 is selected in Updater CE. If you are downloading by hand, that file name is the check.

What the Y2 port gives you

  • Tag-based library — albums and artists read from your files, not the folder names.
  • Playback features — gapless playback, crossfade and the equalizer.
  • Themes — theme support follows the build; check the release notes for the tag you install rather than assuming a Y1 theme pack applies.
  • Offline by design — local files, no account, no subscription.
  • A way back — the Y2 Original Software package restores the stock player.

It is a beta line. That is not a warning to avoid it, but it does change how you should read release notes: features can move between builds, and a theme that worked on one beta may need the next one.

Which Y2 build do I want?

  • Only install builds listed for Y2 — the model filter in Updater CE is the safest list you will find.
  • Take the newest beta unless a release note warns about something you need.
  • Keep the ZIP you flashed (or its tag name) so you can return to that build if a later beta misbehaves.

The full history is on the Rockbox-Y2 release notes.

Where the Rockbox-Y2 ROM zips come from

The Y2 mirror is y1-community/y2-rockbox-mirror. Its releases repack the port as portable flashing packages: rom_y2-windows.zip, rom_y2-macos.zip, rom_y2-linux.zip and a universal rom_y2.zip, alongside the project's own notes and guides.

Those are the same images Updater CE flashes when you install from the app. The Rockbox ROM download page lists Y1 and Y2 packages together so the model is never ambiguous.

Install Rockbox-Y2

  1. Open Innioasis Updater CE and set Device Model to Y2.
  2. Choose Rockbox in Software.
  3. Pick a release explicitly listed for Y2.
  4. Click Install / Restore and wait for the package to prepare.
  5. Power the Y2 fully off, then connect the USB data cable only when Updater asks.
  6. Disconnect after the success message, then boot the player.

The long version is the Rockbox-Y2 tutorial.

Going back to the original Y2 software

Choose Y2, choose Original Software, pick a stable release and run Install / Restore. The restore page and the Y2 stock-software page have the sequence.

Questions people ask

Can I use a Y1 Rockbox tutorial for the Y2?

For the broad idea, yes — model first, software second, connect last. For package choice and theme notes, follow the Y2 guide.

Why does the file name say rom_y2.zip?

Because it is the Y2 ROM. That naming is the simplest way to confirm a manual download belongs to this player.

Do Y1 themes work on the Y2?

Not reliably. Theme support follows the Y2 build; check its release notes and the Rockbox-Y2 theme page.

Is there a stable Y2 release?

The line is published as betas. Take the newest unless a note says otherwise, and keep the tag you flashed.
