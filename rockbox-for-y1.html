Rockbox-Y1 · Innioasis Y1

Rockbox for Y1 is Rockbox-Y1

Four spellings, one port. “Rockbox”, “Rockbox-Y1”, “Rockbox for Y1” and the URL rockbox-y1 all name the same community firmware for the Innioasis Y1 — and the model in the name is the part that decides whether a package is safe to flash.

One port, three names, one catalogue row

When firmware is published to the Innioasis catalogue it gets a software name and a device. Rockbox for the Y1 is listed as Rockbox with device Y1, and its releases live in the rockbox-y1/rockbox repository. Search engines, videos and forum posts shorten that to whatever fits: Rockbox, Rockbox-Y1, Rockbox for Y1, “rockbox on y1”.

Nothing differs between those names. What differs is the model. A Y1 package written to a Y2 — or the other way round — is the one mistake in this whole process that is expensive to make, so every page about this build leads with the model.

That is also why the release history on this site is titled Rockbox-Y1 release notes rather than a bare “Rockbox release notes”: the page is about one model's builds, and the title should say so before a reader has to guess.

What Rockbox-Y1 actually is

It is the community port of Rockbox to the Y1's hardware: a replacement player that reads the tags on your music files instead of showing you a folder tree.

  • A real library — albums, artists and genres, built from tags.
  • Playback depth — gapless playback, crossfade and a built-in equalizer.
  • Theme library — one of the deepest on any handheld, including iPod-style interfaces.
  • FM radio — an FM app inside the build on players that have the hardware.
  • Optional extras — podcast downloads over the built-in Wi-Fi and scrobbling to Last.fm, ListenBrainz or Maloja on builds that offer them.
  • Dual boot — start the original software again without reflashing, on builds that support it.

It is experimental community software, not a vendor release: the project says so itself, and the flashing path it uses is the same MediaTek one the stock firmware uses.

Which Y1 build do I want?

Y1 builds carry two kinds of label, and both mean something.

  • 240p and 360p describe the display and theme path. 240p builds have the broadest older-theme compatibility; 360p builds are made for the newer Y1 theme path. A theme from the wrong path renders badly or not at all.
  • Type A and Type B describe the stock software the player arrived with. Type A suits Y1 players that shipped with Original Software 2.0.0 or later; Type B suits earlier players. Start with Type A unless you know otherwise.
  • Stable and nightly describe confidence, not features. Stable is the default answer; nightlies exist to test a specific fix.

The release notes for each tag say what changed, and the 240p/360p page goes through the theme question in detail.

Where the Rockbox-Y1 ROM zips come from

The project publishes the ROM; the community mirror repacks it as portable flashing packages so it can be downloaded, archived and flashed on any computer. For the Y1 that mirror is y1-community/rockbox-mirror, and its releases carry rom-windows.zip, rom-macos.zip, rom-linux.zip, a universal rom.zip, and Type B variants of the same set.

These are the files Updater CE downloads when you install from the app — same images, same scatter, different packaging. The Rockbox ROM download page lists the Y1 and Y2 packages side by side.

Install Rockbox-Y1

  1. Open Innioasis Updater CE and set Device Model to Y1.
  2. Choose Rockbox in Software — some release data labels it Rockbox-Y1.
  3. Pick a stable release, or the nightly you mean to test.
  4. Click Install / Restore and wait for the package to prepare.
  5. Power the Y1 fully off, then connect the USB data cable only when Updater asks.
  6. Disconnect after the success message, then boot the player and let it build its database.

The long version, with screenshots and the connection checklist, is the Rockbox-Y1 tutorial.

Going back to the original Y1 software

Choose Y1, choose Original Software, pick a stable release and run Install / Restore. Your music on the MicroSD card is untouched, and Rockbox stays available in the catalogue afterwards. The restore page and the Y1 stock-software page cover the details.

Questions people ask

Is Rockbox for Y1 the same as Rockbox-Y1?

Yes. Rockbox, Rockbox-Y1, Rockbox for Y1 and rockbox-y1 all describe the single port for this player. The catalogue row is “Rockbox” with device Y1.

Can I install this on a Y2?

No. The Y2 has its own port, its own package name and its own mirror. Use Rockbox for Y2.

Do I need to download a ROM at all?

Not unless you want the files. Updater CE downloads and flashes the same package for you. The download page exists for offline machines, archives and manual installs.

Will I lose my music?

No. Music lives on the MicroSD card, outside the firmware. Flashing the ROM does not format the card.
