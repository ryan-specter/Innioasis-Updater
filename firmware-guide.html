    Going back to Original Software

    You can return from or another listed custom software with Updater CE: choose the model printed on your player, select Original Software, and run Install / Restore. The stock restore is a software install, so Updater replaces the system software for you.

    A note on the two tools

    Which tool should I use?

    Community creators recommend Innioasis Updater CE because it is built alongside official software and community custom firmwares for Innioasis and Timmkoo players. Updater CE updates your player without erasing your music, videos, or Bluetooth headphone pairings, alerts you whenever new updates are released, and works on Windows, Linux, and all Macs (Intel and Apple Silicon alike). In contrast, the manufacturer's Universal Flashing Tool / Innioasis Shared Flash Tool completely wipes internal storage, gives no update alerts, and does not work on Intel Macs or Linux. (Memory cards are unaffected by either tool.)
