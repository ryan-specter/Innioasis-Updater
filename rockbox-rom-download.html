Rockbox ROM download for the Y1 and Y2

Rockbox ROM downloads for the Innioasis Y1 (Rockbox-Y1) and Y2 (Rockbox-Y2): portable flashing packages from the community mirror, per platform, with the Updater route beside them.

Pick the model first

There is no single Rockbox ROM for both players. The Y1 port and the Y2 port are separate builds with separate mirrors, and the model decides which one is safe to flash. Links below go straight to the mirror release that holds the zips.

What these files are

Each mirror release repacks the ROM from the project's own release as a portable flashing package: a scatter file and the partition images. Updater CE downloads the same images and writes them with MediaTek's download protocol. Nothing here is a mainline Rockbox build for another device, and none of it is an installer.

  • Universal package: one archive for every computer.
  • Per-platform package: the same images, packaged for Windows, macOS or Linux.
  • Type B package (Y1 only): for players that need the Type B build.

Install any of them with the guided flow

If you would rather not handle files, skip the downloads entirely: Updater CE picks the release for your model and flashes it. The Rockbox-Y1 install guide and the Rockbox-Y2 install guide both assume that route.
