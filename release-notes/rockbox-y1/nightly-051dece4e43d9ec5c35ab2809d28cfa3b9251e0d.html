A music-first custom Software with deep playback and theme options.

New:

  • Support for devices that came with stock firmware 3.0.7
  • Black screen bug mitigations
  • Fixes plugins as start screen
  • Fixes audio not pausing on BT disconnect

If you have issues, try these steps:

  1. Full flash of the new ROM.
  2. Delete .rockbox on your SD card.
  3. Install any of the patched themes from here: https://github.com/rockbox-y1/themes/archive/refs/heads/patch.zip
  4. If you want to use any custom themes that worked for older Rockbox-Y1 versions, you will need to change paths in the theme files from /.rockbox to /sdcard/.rockbox
  5. Install font pack: https://download.rockbox.org/release/4.0/rockbox-fonts-4.0.zip
