2.4.0-koensayr-3.0.2

Koensayr is a mod for the Y1's OS that makes the following improvements to the original OS:

Browsing the albums of an artist from Main Menu > Artists > Albums

Adds Bluetooth remote control support and track info displayed on your bluetooth receiver, perfect for using your Y1 in a car with the infotainment system.

Patches (--all)

  • Music-player UX (Artist→Album navigation)
  • Bluetooth pairing (audio.conf / auto_pairing.conf / blacklist.conf / build.prop)
  • System config (ADB debugging, bloatware removal)

  • AVRCP 1.3 metadata + control + Y1Bridge

Diagnostic scripts (tools/dual-capture.sh, gdb attach, btlog-dump) are not included in the ROM — see the repo Diagnostics.

After flash

If AVRCP / MultiDex classes fail to load after upgrading from a prior koensayr build:

adb shell rm -rf /data/data/com.innioasis.y1/code_cache/secondary-dexes/
