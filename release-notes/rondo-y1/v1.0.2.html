Rondo 1.0.2

Community firmware package for the Y1.

v1.0.2Y12026-11-03jarvissax/rondo
Get it in Updater CEFirmware Downloads

Rondo 1.0.2 is about the server: it now updates itself with one click from its admin page. Nothing changes on the Y1 itself; it still offers this version as an update so the Y1 and the server stay on the same number.

What's new

  • Update the server with one click. When a newer Rondo is out, the server's admin page offers Update: the server downloads the new version and restarts on it in a minute or two, keeping your settings, YouTube account and connected Y1. A small companion container, rondo-updater, does the work; it only ever touches the Rondo server's own container, and if the new version doesn't start, the old one comes back by itself.
  • Ready-made server images. Installing the server now downloads it instead of building it on your machine, for regular PCs and 64-bit ARM (Raspberry Pi 4 and 5, many NAS boxes). The first start is much quicker on small machines.

The full list is in CHANGELOG.md.

Moving your server over

A server set up before 1.0.2 built itself and has no updater yet. Update it by hand once, and Update on the admin page does it from then on:

cd rondo
git pull
docker compose -f infra/compose.home.yaml pull      # or compose.vps.yaml
docker compose -f infra/compose.home.yaml up -d

Your admin password, YouTube account and connected Y1 stay. Details: Keeping it running.

The Y1

If your Y1 runs Rondo 1.0.1, Settings › Software update, Install in the dashboard or the update page bring it to 1.0.2 in a minute; nothing else changes. New to Rondo: choose Rondo in Innioasis Updater CE (Y1, then Type A), or install rom.zip below with the Updater's Settings › Install from a file…. Only for the Y1 Type A.

Files

  • rom.zip: the firmware, for Innioasis Updater CE (Y1 Type A), built from rondo-1.0.2.apk by the release workflow.
  • rondo-1.0.2.apk: the update, for a Y1 that already runs the Rondo firmware.
  • updater.png: the picture Innioasis Updater CE shows for this release.
  • The server images: ghcr.io/jarvissax/rondo-server:1.0.2 and ghcr.io/jarvissax/rondo-updater:1.0.2 (also latest).
