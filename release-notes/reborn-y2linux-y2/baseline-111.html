Y2Linux 1.0 Beta 8.14: real shuffle, gentler seeking. Linux 6.18 and the native Reborn music player for the Innioasis Y2.

Already running Y2Linux

Settings → About & Updates → Check for Updates → Update Now.

What's new

  • Shuffle is really random now. Every Shuffle used to play the same order, because the order was worked out from the song instead of from chance, and Shuffle on an album or playlist always started with its first song. Each Shuffle now gets a fresh random order and may start with any song. A song you pick while Shuffle is on still plays first.
  • Seeking starts small. Holding Previous or Next used to jump 30 seconds about ten times a second. It now moves 1 second at a time, speeds up to 3 and then 10 seconds the longer you hold, and never jumps more than about a sixtieth of the song.
  • Shuffle on genres. A genre now has a Shuffle row under All Songs, as on an album.
  • Long song titles on the Home screen now end with "…" instead of running into the menu.
  • The automatic Internal Storage setup no longer logs a harmless storage error, which used to send a false error report.

Thanks to everyone who sent reports and suggestions. Japanese, Chinese and Korean text is planned next.

Everything from Beta 8.13 is included.

Install (from stock)

You need SP Flash Tool v5.2032, a USB cable, Y2Linux-1.0.0-beta.8.14-first-install.zip below and the Innioasis Y2 firmware package v3.2.0 from Innioasis (only this version works; it is also your way back to stock).

  1. Unpack both.
  2. SP Flash Tool → Download Only → load MT6582_Android_scatter.txt from the Y2Linux zip. Exactly BOOTIMG, RECOVERY, ANDROID and USRDATA are ticked.
  3. Click Download and connect the switched-off Y2; wait for the green tick.
  4. Unplug and press Power: the player sets up its Internal Storage (a few seconds), then Y2Linux and Reborn start, music works.
  5. Connect the Y2 to the computer and copy (don't move) system.img from the Innioasis package into the Firmware folder on Internal Storage. The player takes the Wi-Fi/Bluetooth firmware from it and turns the radios on.

Known issues (beta)

  • The highest volume is still lower than stock's, even at High; demanding headphones may want more.
  • A headphone profile still uses some extra processor time while it plays; its effect on battery life has not been measured yet.
  • The restart fix of Beta 8.4 is not yet confirmed over many restarts. If the screen ever stays dark, hold Power for 10 s and start again.
  • Battery life in sleep is not yet stock-like (about 8 mA vs stock 1.3 mA; some players draw more, #42).
  • GC9503V players keep the old screen-off behaviour until a GC9503V owner has confirmed the new sequence (#45).
  • The charging fix (#47) is not yet confirmed on an affected player; if yours still doesn't charge, please send a report (Send Report Now, or Save Report and attach it).
  • The player cannot detect wired headphones yet; the jack plays whenever no Bluetooth headphones are connected.
  • The fast copy path has not yet been tested with the cable pulled mid-copy, across sleep, or with Windows Explorer.
  • Songs with several artists ("A;B") count as one artist; there is no Album Artist view yet.
  • FM radio is in the works for a later beta.
