InniClassic 1.4.4

A classic-style Y1 Software.

v1.4.4Y12026-09-29
Get it in Updater CEFirmware Downloads

A hardware-input overhaul: a real Hold/lock switch, a proper video/music handoff, and a round of Now Playing and Videos polish.

Added

  • Hold (key lock) — hold Center for 0.8s to lock the wheel/buttons (and physically turn the display off); hold Center again to unlock. This is the real fix for "screen wakes up randomly in my pocket": instead of guessing which button presses are accidental, you can now lock input entirely, matching the real iPod Classic's Hold switch.
  • Toggle Favorite is back in the Now Playing hold-menu (long-press Play/Pause) — caught and fixed before release: the redesigned Center gesture handling below removed the old "double-click Center" favorite shortcut without anywhere else to reach it.

Fixed

  • Video Play/Pause was starting music instead of pausing the video. Two compounding bugs: the hardware media-button receiver didn't know about video and would call the music player regardless of what was on screen (with "Screen Off Control" enabled), and opening a video didn't stop any music that was already playing. Both fixed.
  • Videos list ignored the wheel/Center in some cases — the screen was unconditionally swallowing every key before the shared list-navigation code could see it.
  • Now Playing wheel seeking is now a real preview-then-confirm: turning the wheel in Seek mode moves a pending position in 5-second steps without touching actual playback, applied only once you press Center again. The preview no longer gets silently overwritten by the background progress update.
  • Center-button handling is now centralized in one place — fixes a hold sometimes also registering as a select, and holding Center no longer opens the song menu or toggles video seek mode (that's long Play/Pause and short Center respectively now).
  • Pausing on the Classic theme no longer dims the album artwork or leaves a leftover audio-format overlay on screen; the selected Now Playing bottom-bar mode survives a pause/resume.
  • Removed a duplicate progress-callback registration.

Changed

  • More compact Now Playing progress/volume bars, fixed-width time labels, and evenly spaced rating marks.
  • Video now seeks via Previous/Next (±10s); the wheel is volume-only during video playback.
  • Classic Videos list shares the same background/row styling as every other list.

Full engineering write-up: docs/release-review-1.4.4.md.

Install

  • rom.zip — flash via the Innioasis Updater, no ADB required. Must keep the filename exactly rom.zip.
  • InniClassic-1.4.4.apk — install over an existing JJ Launcher / InniClassic install via adb install InniClassic-1.4.4.apk.
