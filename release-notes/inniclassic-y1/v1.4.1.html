InniClassic 1.4.1

A classic-style Y1 Software.

v1.4.1Y12026-08-28
Get it in Updater CEFirmware Downloads

Video feature catch-up, a new boot logo, and another round of Reddit-reported fixes.

Added

  • Video thumbnails — the Videos list shows a real frame from each file instead of a generic icon, loaded in the background.
  • Video resume-position — playback remembers where you left off and jumps back there next time you open that file.
  • Fill Video Screen setting — Settings → Fill Video Screen lets you choose between the original aspect ratio (letterboxed) or filling the whole screen. Direct response to a GitHub issue request.
  • New boot logo — replaces the Rockbox-branded splash the ROM's LOGO partition had carried over since this project's very first release with a plain black screen showing "InniClassic".

Changed

  • Larger list/settings text — Songs/Albums/Artists/Genres/Composers rows, folder browsing, and every Settings row are a bit bigger.
  • Cover Flow now groups by artist — previously sorted purely alphabetically by album title; now sorted by artist first, album second, matching the real iPod Classic.

Fixed

  • Folders with many files lagged noticeably when opened — rows now build in chunks instead of all at once, so the screen stays responsive.
  • Screen could randomly wake up in a pocket while listening to music — only the Center button now wakes the real display back up (was any key before, which pocket pressure on the wheel could trigger).

Install

  • rom.zip — flash via the Innioasis Updater, no ADB required. Must keep the filename exactly rom.zip.
  • InniClassic-1.4.1.apk — install over an existing JJ Launcher / InniClassic install via adb install InniClassic-1.4.1.apk.

Full changelog: https://github.com/FabianZettl/inniclassic/blob/master/CHANGELOG.md
