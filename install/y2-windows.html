Innioasis Y2 · Windows

Install software on Innioasis Y2 with a Windows PC

The Innioasis Y2 is the second-generation click-wheel player, with a larger screen and the same offline music-first design. Its stock software is archived as rom_y2.zip. Y2 packages are not interchangeable with Y1 packages, even when a release carries both files, so the model check is the most important step before any install. These are the Windows routes for the Innioasis Y2.

Prepare Windows for the install

  1. Download the Innioasis Updater CE installer (installer.exe) from the official GitHub release and run it. If SmartScreen says “Windows protected your PC”, choose More info then Run anyway only for the file you just downloaded from github.com/y1-community/Innioasis-Updater.
  2. Install the MediaTek USB driver with DriverInstall.exe, then restart the PC. The driver is what lets Windows see a powered-off player when Updater CE asks for it.
  3. Use a USB port on the PC itself and a cable that carries data. A charge-only cable or an unpowered hub is the usual reason the player never appears.

Windows 10 and 11 x64 are the normal targets. ARM64 Windows is experimental. Full Windows setup notes.

Questions people ask

Can I install custom software on the Innioasis Y2 with Windows?

Yes, when the project lists the Innioasis Y2. Every project card above opens the Windows guide for that software and model.

Do I need a driver on Windows?

Yes, install the MediaTek driver and restart.

Will I lose my music?

Back up first. A full system install can wipe internal storage; the microSD card is normally left alone.

How do I restore the factory software?

Choose the model and Original Software in Updater CE, pick a stable release, then run Install / Restore.
