Innioasis G5 · Software and firmware

Innioasis G5 software and firmware install guides

The Innioasis G5 is the newer, faster G series player, built on the MT6765 platform with modern Android partitions. Its factory software is archived as rom_g5.zip. The G5 is not a G1 or G3 image: use the package that names the G5 and the scatter file that ships inside it.
