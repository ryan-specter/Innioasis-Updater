Timmkoo SR1 · Software and firmware

Timmkoo SR1 software and firmware install guides

The Timmkoo SR1 is a dedicated recorder built on the R1 Plus hardware. Its factory software is archived as rom_sr1.zip. The SR1 is a recorder, not a player, and its package must not be used on an R1 or PR1.
