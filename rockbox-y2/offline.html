Rockbox-Y2

Rockbox-Y2 plays the files on your card. There is no account, no streaming service and no subscription — which is exactly why a lot of people install it.

Get it in Updater CEFull written tutorial

An offline player by design

  • The library is built from tags on your own files.
  • Playback, the equalizer and the themes work with no network at all.
  • Nothing about your listening requires a login.
  • Podcast and scrobbling features are optional extras, not requirements.

If you are moving a library off a streaming service, the practical order is: copy the files to the card, boot the player, refresh the database, then tune the settings.

What it is not

It is not a streaming client and it does not download your subscriptions. It replaces the player software; your music still has to exist as files.

Questions people ask

Does it need Wi-Fi?

No. Wi-Fi is only used by optional features on builds that offer them.

Which formats?

Rockbox's usual set — MP3, FLAC, AAC and Ogg among them. Check the release notes for the build you install if you rely on an unusual format.

Is my listening data sent anywhere?

Only if you configure scrobbling yourself.
