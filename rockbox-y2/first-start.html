Rockbox-Y2 first start

The first boot after a Rockbox-Y2 install is not the end of the job: the player builds its database, creates the settings folder on the card, and waits for music.

Get it in Updater CEFull written tutorial

What happens on the first boot

  1. Start the player and let it finish its first-boot routine — do not pull the card.
  2. Insert a MicroSD card with music on it (FAT32/exFAT is the safe choice).
  3. Let the database build; large libraries take a while the first time.
  4. Install a theme that matches your build, then reboot to see it applied.

Worth changing on day one

  • Database → update now, once the music is on the card.
  • Theme settings, so the wheel and the screen match how you browse.
  • Playback settings: gapless and crossfade are the two people notice first.
  • If the build supports it, point scrobbling at your Last.fm / ListenBrainz / Maloja account.

Themes are covered on the Rockbox-Y2 theme page, and the card layout on the MicroSD page.

Questions people ask

The player booted with no music — is the install broken?

No. Rockbox reads the card, not internal storage. Add music to the card and refresh the database.

Can I install themes before flashing?

You can copy them to the card first, but apply them after the build is running.

How do I get back to stock software from here?

Either from the player's own system menu when the build offers it, or by reflashing Original Software — see dual boot.
