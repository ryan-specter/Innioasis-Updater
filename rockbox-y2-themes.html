Rockbox-Y2 themes follow the build

The Y2 port is a beta line, and theme support moves with it. The safe habit is the same on both players: check the release note for the tag you installed before you assume a theme pack applies.

Start with the build you actually have

Y2 builds are versioned betas rather than a resolution-labelled stable line. That changes the question from “which label does my theme match?” to “does this build support this theme at all?” — which the release notes answer for that tag.

Y1 theme packs are not a substitute: the two ports are separate builds with separate interfaces. See Rockbox-Y1 vs Rockbox-Y2 for the full comparison.

Where themes live on the Y2

Inside the .rockbox folder on the MicroSD card, in its themes folder — the same arrangement as the Y1 port. Settings, themes and caches are card files; the firmware is not.

  1. Boot Rockbox-Y2 once so the folder exists.
  2. Copy the theme's folder into .rockbox/themes.
  3. Select it in the theme settings and reboot.
  4. If the build's release note warns that themes changed in that beta, use a theme made for it.

Turn on hidden files to see the folder: macOS Cmd+Shift+., Windows View → Hidden items, Linux Ctrl+H.

Resetting a theme that broke the interface

Rename or delete .rockbox on the card and boot again: the build recreates it with default settings and a default theme. It does not uninstall the firmware and it does not touch your music.
