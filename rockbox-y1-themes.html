Rockbox-Y1 themes: pick the build, then the look

Themes are the reason the build labels exist. A Rockbox-Y1 theme is written for a display path — 240p or 360p — and it only looks right on a build that matches.

240p, 360p, and why the label is on the build

Y1 community builds are published with a resolution label, and the theme collections carry the same label. 240p builds have the broadest compatibility with older theme packs; 360p builds are made for the newer Y1 theme path. Installing one and applying the other is not dangerous — it just looks wrong, with clipped text, missing elements, or an interface you cannot read.

If you have no theme preference yet, take the newer stable build and its default theme, then choose themes that match its label. The resolution page goes deeper; the rule of thumb is simple: build label and theme label must agree.

Where themes live

Themes are files on the MicroSD card, inside the .rockbox folder — the same folder that holds settings and caches. The firmware itself is on internal flash, so adding, changing or removing a theme never requires reflashing.

  • Copy the theme's own folder into .rockbox/themes on the card.
  • Then choose it in the player's theme settings and reboot to see it applied.
  • Keep a copy of a theme you like before updating the build — it is a file, not an installation.

Turn on hidden files first if you cannot see the folder: macOS Cmd+Shift+., Windows View → Hidden items, Linux Ctrl+H.

Applying a theme, in order

  1. Install and boot Rockbox-Y1 first; a theme needs a running build.
  2. Copy the theme folder to .rockbox/themes on the card.
  3. Open the theme settings and select the theme.
  4. Reboot so the whole interface — not just the menu — picks it up.
  5. If it looks broken, select another theme; the files are still there if you want to retry later.

Undoing a theme that broke the interface

If the player boots into something unusable, you do not need to reinstall the firmware. Rename or delete the .rockbox folder on the card and start the player: the build recreates the folder with default settings and a default theme. Your music is untouched, and you can copy the themes you want back afterwards.

Questions people ask

Will a Y2 theme work on the Y1?

No. The ports are separate, and theme support on the Y2 follows its beta builds. See Rockbox-Y2 themes.

Do themes survive an update?

Usually yes, because they live on the card and the flash writes the ROM. If a new build changes the theme path, reapply a theme that matches its label.

Why is the theme only half applied?

A reboot normally resolves it. If not, the theme's files are incomplete — re-copy its folder rather than editing individual files.
