Innioasis Y2 · Install Tutorial

Install Reborn (Y2Linux) on your Innioasis Y2.

Follow these steps to flash Reborn (Y2Linux / Y2Reborn) onto an Innioasis Y2 using Innioasis Updater CE, then finish the post-install Wi-Fi and Bluetooth setup.

Get Updater CE Why Reborn (Y2Linux)? Y2Reborn Releases

Step-by-step installation

  1. Install and open Updater CE: Download Innioasis Updater CE for Windows, macOS, or Linux and launch the app.
  2. Select your model: In Device Model, choose Y2.
  3. Select Reborn (Y2Linux): In Software, choose Reborn (Y2Linux) and pick the latest release from the release dropdown.
  4. Start the install: Click Install / Restore, power your Y2 completely off, and connect it with a USB data cable when Updater CE prompts you.
  5. Wait for completion: Keep the player still until Updater CE confirms the flash has succeeded, then disconnect the cable.
  6. Complete final setup for Wi-Fi, FM radio & Bluetooth

    There are some final setup steps needed to get Wi-Fi, FM radio, and Bluetooth working on your Y2 using system.img. Follow along with our post-install guide to finish setting up your player.
