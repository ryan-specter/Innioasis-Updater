Innioasis Y2 · Install Tutorial

Install Reborn (Y2Linux) on your Innioasis Y2.

Follow these steps to flash Reborn (Y2Linux / Y2Reborn) onto an Innioasis Y2 using Innioasis Updater CE, then finish the post-install Wi-Fi and Bluetooth setup.

Get Updater CE Why Reborn (Y2Linux)? Y2Reborn Releases

Step-by-step installation

  1. Install Updater CE: Download Innioasis Updater CE for Windows, macOS or Linux, then open it.
  2. Select Y2: Choose Y2 as the device model.
  3. Select Reborn: Choose Reborn (Y2Linux) and the latest release.
  4. Install: Click Install / Restore, power the Y2 off, and connect USB when prompted.
  5. Wait: Keep the player still until Updater CE confirms, then disconnect.
  6. Set up Wi-Fi, Bluetooth & FM radio

    Copy system.img to the player once. Reborn does the rest.

Returning to Original Software

You can return your Y2 to factory software anytime by choosing Y2 and Original Software in Updater CE. See the Y2 restore tutorial.
